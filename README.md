# Udemy-CloneThis project is a single-page front-end clone of the Udemy website, built using HTML and CSS. It replicates the look and feel of an online learning platform’s homepage, focusing on layout design, styling, and responsiveness.

The project demonstrates how a real-world website interface can be structured using semantic HTML and styled with modern CSS techniques.

✨ Features
Single-page layout inspired by Udemy
Responsive design for different screen sizes
Course section with styled cards
Navigation bar and banner section
Clean and organized UI
🛠️ Technologies Used
HTML5
CSS3
